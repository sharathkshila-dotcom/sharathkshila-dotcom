An ESP32-based attendance system using RFID technology.

**Features:**
- RFID card detection
- Student identification
- OLED display
- Servo control
- Buzzer notifications
- Attendance data management
- Google Sheets integration

**Technologies:**  
`ESP32` `MFRC522` `RFID` `OLED` `Servo` `Google Sheets`
